# Mre_des_tools
App demonstrate how to encode/decode data to des.  Password max lenght 8 symbols. Limited size of source file.
For using with Nokia mobile phone, app must be signed with IMSI (your SIM card) code.
https://vxpatch.luxferre.top/
Application files - "[Bin2des.vxp](https://rdzdx.github.io/mre_des_tools/Bin2des.vxp)", "[Bin2des_3250.vxp](https://rdzdx.github.io/mre_des_tools/Bin2des_3250.vxp)", "[Des2bin.vxp](https://rdzdx.github.io/mre_des_tools/Des2bin.vxp)", "[Des2bin_3250.vxp](https://rdzdx.github.io/mre_des_tools/Des2bin_3250.vxp)".
